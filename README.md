# React Profile Cards – Practice Project

A simple practice project built with React.
It displays multiple user profile cards using reusable components and props.

# Features

=> Reusable ProfileCard component
=> Inline styling for quick prototyping
=> User data stored in an array
=> Cards generated using map()
=> Responsive row wrapping with flex layout

# Tech Stack
=> React
=> JavaScript
=> CSS (basic inline styles)
